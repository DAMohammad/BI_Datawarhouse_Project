Pubs BI Project
Overview
This project presents an end-to-end Business Intelligence (BI) solution based on the Pubs dataset.
The project covers the complete BI workflow, from raw data processing and ETL to Data Warehouse implementation, SSAS modeling, and the final analytical dashboard.
Project Workflow
The overall workflow of the project is:
Source Data → ETL → Data Warehouse → SSAS → Dashboard
ETL
The source data was extracted, cleaned, transformed, and prepared for loading into the Data Warehouse.
Data Warehouse
A Data Warehouse was designed and implemented to organize the data into a structured format suitable for analytical queries and reporting.
SSAS
An analytical model was developed using SQL Server Analysis Services (SSAS) to enable data analysis and support business reporting.
Dashboard
The processed and modeled data was used to create a BI dashboard for presenting key insights and analytical results from the Pubs dataset.
